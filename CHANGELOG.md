# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple release-based changelog format inspired by Keep a Changelog and Semantic Versioning.

## [Unreleased]

### Added

- Repository workflow baseline with issue and pull request templates.
- Architecture Decision Record directory for documenting major technical decisions.

### Changed

- Development workflow now moves toward issue-driven and pull-request-based changes.

### Security

- Added security-focused issue template for authentication, authorization, session, dependency, and hardening tasks.

## [v0.1.0] - 2026-06-06

### Added

- Post-MVP baseline release.
- Personal finance tracking functionality.
- Budgeting and savings goal tracking.
- Export support.
- Docker-based deployment support.
- CI workflow for quality checks.

### Known Limitations

- Application is still oriented around personal or single-user usage.
- Authentication model is not yet designed for complete multi-user usage.
- Role-based access control is not yet implemented.
- User-owned data isolation is not yet implemented.
- Multi-user database migration strategy is not yet defined.
